# Portfolio Project Brief

## Goal

Build a professional web developer portfolio for David Ivankov.

The portfolio should make me appear highly hireable to recruiters by showing that I can build, ship, explain, and maintain real web products.

The portfolio will focus on case studies, starting with my AI Meeting Notes Tool.

## Positioning

I am a web developer building practical SaaS-style web applications with:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel
- AI-assisted development workflows

I want to present myself as a frontend / full-stack leaning web developer who can ship real products, not just tutorial projects.

## Main project to feature

AI Meeting Notes Tool

Important proof points:

- Real SaaS-style product
- Invite-gated beta
- Public landing page
- Request access flow
- Pricing page
- Privacy page
- Terms page
- How it works page
- Sample meeting / public demo page
- Deployed on Vercel
- Built with modern web stack

## Portfolio pages

First version should include:

- Home
- Case Studies
- AI Meeting Notes Tool case study
- About
- Resume / Contact

## Design direction

Clean, professional, recruiter-friendly.

Avoid:

- Overly flashy animations
- Complex 3D effects
- Unnecessary dependencies
- Over-engineered architecture
- Generic template look

Prioritize:

- Clear copy
- Strong case study
- Mobile-first layout
- Fast loading
- Good typography
- Semantic HTML
- Accessibility basics
- SEO basics

## AI workflow rules

AI can help with:

- Drafting layout ideas
- Improving copy
- Creating small components
- Refactoring
- Reviewing code
- Explaining errors
- Suggesting tests and checks

AI must not:

- Build the whole project in one prompt
- Add dependencies without permission
- Change unrelated files
- Create code I cannot explain
- Overcomplicate the project

Every task should be small and reviewable.

## Definition of done for every change

Before committing:

- I understand every changed file
- The page works on mobile and desktop
- The code is simple and maintainable
- No unnecessary dependencies were added
- No unrelated files were changed
